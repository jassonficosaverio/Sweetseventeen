# Sweet Seventeen 💜

Website ulang tahun ke-17 (tema lavender + rose gold). Murni HTML/CSS/JS, tanpa build.

## Cara mengganti isi
Buka `script.js`, edit blok `CONFIG` di paling atas:
nama, tanggal, isi surat, caption foto, dan doa/harapan.

## Foto & musik
- Foto: taruh di `assets/photos/` dengan nama `1.jpg` … `6.jpg` (atau ubah daftar di CONFIG).
- Musik: taruh lagu sebagai `assets/music.mp3` (opsional).

## Mencoba sebelum hari H
Tambahkan `?preview=1` di URL, contoh: `https://username.github.io/repo/?preview=1`
Tanpa itu, kejutan terkunci dan hanya countdown yang terlihat sampai 12 Januari 2027 00:00 WIB.

## Upload ke GitHub Pages
1. Buat repository baru, upload semua file ini.
2. Settings → Pages → Branch: `main` / root → Save.
3. Buka link yang diberikan GitHub.
